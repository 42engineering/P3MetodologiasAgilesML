# Modeling Objective**

PT1.1 — Up/Down Direction Prediction using LSTM and hybrid LSTM+CNN models
Predict the direction of Tesla (TSLA) stock closing price for the next trading day.
The model must classify whether:

- the price will increase (`1`)
- or decrease/not increase (`0`)

using historical financial market information.


# Baseline Model Report**

The baseline model corresponds to the first learning approach implemented using LSTM. This model was named LSTM1.
Its objective is to establish a performance baseline that can later be used to compare more complex architectures such as DeepLSTM1 and CNNLSTM1.

The model uses a simple LSTM architecture to capture temporal patterns present in historical financial market data. The model output corresponds to a binary classification indicating whether the stock closing price will increase or decrease in the next analysis period.


# Model Description

The implemented baseline model corresponds to an `LSTM1` architecture, used as the first approach to solving the binary classification problem of predicting the future direction of Tesla's stock price.

The model consists of:

* One LSTM layer with 64 neurons.
* One dense output layer with a sigmoid activation function.

The architecture was designed to capture temporal patterns present in financial time series using historical price and volume sequences.

---
# Input Variables

The variables used as model inputs were:

* Open
* High
* Low
* Close
* Volume

These variables were normalized using `MinMaxScaler` and then transformed into time sequences for neural network training.

# Target Variable**

Different time-series windows were used, with configurations of [5, 10, 15, 20, 30] days.

# Target Variable**

The target variable used was:

* `SubeBaja`

This variable represents the future direction of Tesla's closing price:

* `1`: the price will increase.
* `0`: the price will decrease or remain unchanged.

The variable was generated by comparing the current closing price with the closing price of the next trading day.

# Results Analysis

The baseline model made it possible to validate the complete training, evaluation, and prediction pipeline using Tesla financial data. The LSTM architecture was able to partially capture temporal patterns present in the time series.

However, the resulting performance was limited due to the high volatility and inherent complexity of financial markets. Accuracy close to 50% suggests that the model still has difficulty generalizing robust predictive patterns.

The main weaknesses of the model include:

* Relatively simple architecture.
* Limited learning depth.
* Sensitivity to financial noise.
* Lack of additional technical variables.

---

# Conclusions**

The `SimpleLSTM` model served as an appropriate baseline for the project and established a reference point for comparing more complex architectures.
The results show that predicting stock market movements is a highly complex and nonlinear problem. Possible future improvements include:

* Using deeper LSTM architectures.
* Incorporating Dropout layers and regularization techniques.
* Including financial technical indicators.
* Tuning hyperparameters.
* Increasing the size and diversity of historical data.
